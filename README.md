# tree-sitter-raku

A [tree-sitter](https://tree-sitter.github.io) grammar
for [Raku](https://raku.org).

## Layout

- `grammar.js`: the grammar
- `src/scanner.c`: external scanner
  for the context-sensitive parts of the language
- `queries/`: `highlights.scm`, `locals.scm`, `tags.scm`, `injections.scm`
- `test/corpus/`: corpus tests (`npx tree-sitter test`)
- `examples/`: larger sample files

## Usage

```sh
npm install
npx tree-sitter generate     # writes src/parser.c (takes ~2 minutes)
npx tree-sitter test
npx tree-sitter parse examples/stress.raku
```

## What it covers

- Declarations: `my`/`our`/`has`/`state` with types and traits, `sub`/`method`/
  `submethod` with `multi`/`proto`, full signatures (slurpies, named, invocant
  markers like `::?CLASS:D:`, `where`, defaults, coercion types `Int()`),
  `class`/`role`/`grammar`/`module` including `unit` forms and
  `Name:ver<…>:auth<…>` adverbs, `regex`/`token`/`rule`, `enum`, `subset`,
  `constant`, operator subs like `infix:<±>`.
- The Raku operator precedence table, list assignment, listop calls without
  parentheses (`say map &f, @a`), `.method: args` colon calls, private and meta
  method calls (`self!m`, `.^name`), hyper `>>.`, reduction `[+]`, subscripts
  `@a[0;1]`, `%h<a>`, `%h{…}:exists`, colonpairs.
- Control flow: `if`/`elsif`/`else`, `unless`, `with`/`orwith`/`without`, `for`,
  `while`/`until`, `loop`, `repeat`, `given`/`when`/`default`, `whenever`,
  statement modifiers, labels, phasers, statement prefixes (`do`, `try`,
  `gather`, `start`, `react`, …).
- Statement ends: a block-closing `}` at end of line ends the statement, as in
  Raku.
- Strings: `'…'`, `「…」`, `"…"` and `qq` with interpolation of `$var`,
  `@a[…]`, `%h<…>`, `&f(…)`, `$x.method()` and `{ code }`; `q`/`Q`/`qw`
  with any delimiter and nested brackets; heredocs `q:to/END/` (also several on
  one line); `<word lists>`.
- Regexes: `/…/`, `rx`, `m`, `s///`, `s{…} = …`, `tr///`, with adverbs.
  Regex bodies are single opaque `regex_body` nodes;
  their internal structure isn't parsed.
- Comments `#`, embedded `` #`( … ) ``, declarator `#|` `#=`, Pod blocks
  (`=begin`/`=end`, paragraph and abbreviated blocks, `=finish`).

## Known limitations

- `src/parser.c` is large
  (about 100 MB, 17k states),
  because the deep operator table multiplies with the many places an expression
  can appear.
  It compiles fine but slowly, and it's over GitHub's 100 MB file limit,
  so regenerate it instead of committing it, or ship the compiled parser.
- Raku's parser knows which names are subs and which are types.
  This grammar guesses: a bare word followed by a term is a listop call
  (`foo -1` is `foo(-1)`).
  Quote keywords (`s`, `m`, `q`, `tr`, `y`, `x`) can't be used
  as sigilless names or as `=>` keys.
- Heredoc bodies are one opaque node (no interpolation structure).
- Not handled: meta-operators beyond `[op]`, `Z`, `X` and `>>.` (e.g. `»+«`,
  `[R//]=`), `$x:adverb` variables, slangs and custom operators other than
  their declarations.
